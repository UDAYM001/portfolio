# 🌐 Manchu Uday Kiran — Portfolio

A 3D-animated developer portfolio with an AI chat assistant that answers questions about my
projects, skills and background — plus an offline fallback so it never goes silent.

**Live:** https://udaym001.github.io/portfolio/

## ✨ Features

- **Spline 3D hero** with a typing name animation and a graceful gradient fallback
- **AI chat assistant** — real LLM answers when a backend is deployed, a built-in
  offline answer engine when it isn't
- **Dynamic project grid** rendered from a single `PROJECTS` array
- **Interactive effects** — 3D tilt cards, spotlight reveal, pulse-glow accents
- **Dark / light theme** that persists and applies before first paint
- **Working contact form** — endpoint delivery, or pre-filled mailto as a fallback

- **Accessible** — skip link, visible focus rings, ARIA labels, `prefers-reduced-motion` support
- **Resume download**, scroll-spy navigation, mobile menu, SEO metadata + structured data

## 🧠 The chat assistant

The widget has two layers:

1. **Offline engine (always on).** An intent-matching knowledge base with word-boundary
   scoring. Handles projects, stack, resume, contact, education, and direct project
   lookups. No network, no API key, instant.
2. **Real AI (optional).** If a backend is reachable, answers are generated by an LLM
   with my real project data injected as context. If the backend is missing, slow, or
   erroring, the widget transparently falls back to the offline engine — visitors never
   see an error.

The page finds the backend on its own: it probes `/api/chat` (same origin) on load.

### Enabling the AI backend (free, no API key)

The site is hosted on GitHub Pages, which cannot run serverless functions, so the
backend ships as a **Cloudflare Pages Function** in `functions/api/chat.js`.

1. Create a free Cloudflare Pages project connected to this repository.
   - Build command: *(leave empty)*
   - Build output directory: `/`
2. In **Settings → Functions → Workers AI binding**, add a binding named `AI`.
3. Open the Cloudflare URL. The chat header switches to **"AI · online"**.

Prefer a different model? Set one of these environment variables instead:

| Variable | Effect |
| --- | --- |
| `GROQ_API_KEY` | Uses Groq (fast + free tier) |
| `OPENAI_API_KEY` | Uses OpenAI |
| `AI_MODEL` | Overrides the model id |
| `ALLOWED_ORIGIN` | Allows the GitHub Pages copy to call the API cross-origin |

> Without any binding the function returns `503`, and the page silently uses the offline engine.

## ⚙️ Configuration

Everything you'd normally need to edit lives in one `CONFIG` block near the top of the
`<script>` in `index.html`:

```js
const CONFIG = {
  name:   'Manchu Uday Kiran',
  email:  'udaymanchu001@gmail.com',
  resume: 'pdfs/UDAY.pdf',

  social: {
    github:    'https://github.com/UDAYM001',
    linkedin:  '',   // ← fill in to show the icon; empty hides it
    whatsapp:  '',
    instagram: ''
  },

  contactEndpoint: '',  // e.g. a Formspree URL; empty = pre-filled mailto
  chatEndpoint:    ''   // empty = auto-detect /api/chat
};
```

Social icons with an empty URL are hidden automatically, so no dead links can ship.
Projects are edited in the `PROJECTS` array directly below it.

## 🚀 Local development

No build step — just serve the folder:

```bash
python3 -m http.server 8000
# or: npx serve .
```

Then open http://localhost:8000

To test the AI backend locally:

```bash
npx wrangler pages dev .
```
